## Contents

V1.2.0 is a UI/UX-only release:

- Settings category hub with nine categories.
- Dedicated pages for Protection, Authentication & Recovery, Vaults,
  Notifications, Appearance, Permissions, Security & Monitoring, and Battery &
  Background Operation.
- About remains the existing About screen.
- Minimal Home with one protection overview, one prioritized warning, up to three
  accurate stats, three shortcuts, and optional recent activity.
- Quieter five-tab floating navigation pill.
- Version `1.2.0` / code `13`.

Unchanged:

- authentication, lockout, recovery, and decoy logic;
- vault credentials, keys, containers, indexes, import/export, and capture;
- protection service, detection channels, permissions, and notification flow;
- security journal and storage;
- manifest, application ID, and signing identity;
- frozen decoy source.

## Distribution guidance

- Treat this as a **local, build-verified, emulator-smoke-tested release**, not a
  store release.
- Do not publish the APK as a production-signed app.
- Replace the debug signing config with an owner-held keystore before any public
  distribution.
- Run the device acceptance checks on at least one Android 8+ and one Android 14+
  device before relying on protection.
- Keep the APK and checksum file together.

## Known issues

- Android Lint is unavailable on the 8 GB build host.
- The release uses the debug signing key.
- Full unlock, lockout, decoy timing, vault import/export, camera capture,
  protected-app overlay coverage, and physical-device upgrade migration were not
  exercised.
- Only one API 37 x86_64 emulator image was used.
