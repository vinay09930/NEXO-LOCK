succeeded, the app launched, and the existing setup state and journal were
preserved. The current Home capture (`01b_home_recent_activity.png`) shows the
optional recent-activity section with the latest journal entries.

## Honest conclusion

V1.2.0 compiles, passes the existing 149 JVM tests, builds the release APK, and
was exercised on an API 37 emulator for first-run setup, Home, the Settings hub,
all nine category pages, About, back navigation, the floating pill, the Home
warning action, and a vault shortcut. The RELEASE APK installed over the previous
same-key release and preserved existing setup data. The security and decoy logic
was not modified, and the frozen decoy hashes still match.

The release is **not** a full device acceptance test. Treat it as a
build-verified, emulator-smoke-tested UI delivery that still needs real-device
testing for protection, unlock, vault, capture, and upgrade paths.
